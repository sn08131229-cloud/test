# 医疗器械流转多方查验平台 V1 运行说明

## 项目结构
- `frontend/`：Vue3 + Vite 前端
- `backend/`：Spring Boot 后端（REST API + ChainService）
- `docs/sql/init.sql`：MySQL 初始化脚本

## 1. 前端（VS Code）
```bash
cd frontend
npm install
npm run dev
```
默认地址：`http://localhost:5173`

前端通过 `VITE_API_BASE_URL` 访问后端：
`frontend/.env.development`
```env
VITE_API_BASE_URL=http://localhost:8080/api
```

## 2. 后端（IDEA）
- 用 IntelliJ IDEA 打开 `backend/`
- 运行主类：`com.example.trace.TraceApplication`

也可命令行：
```bash
cd backend
mvn spring-boot:run
```

### 后端配置（application-dev.yml）
- `server.port=8080`
- `spring.datasource.url=jdbc:mysql://localhost:3306/medical_device_trace`
- `spring.datasource.username=root`
- `spring.datasource.password=你的密码`
- `chain.mock=true/false`
- `chain.webaseFrontUrl=http://虚拟机IP:5002/WeBASE-Front`
- `chain.groupId=1`
- `chain.contractAddress=合约地址`

## 3. MySQL 初始化
```bash
mysql -uroot -p < docs/sql/init.sql
```

## 4. WeBASE-Front / FISCO BCOS
- 由 Ubuntu 虚拟机独立启动
- 后端通过 `chain.webaseFrontUrl` 配置连接
- 不内置在后端，不暴露给前端

## 5. Mock / Real 链切换
- `chain.mock=true`：使用 `MockChainService`
- `chain.mock=false`：切换到真实链服务（待补 RealChainService HTTP 调用）
- 业务流程只依赖 `ChainService`

## 7. 已实现接口
- 登录：`POST /api/login`
- 设备：`GET/POST /api/devices`、`GET /api/devices/{deviceCode}`、`GET /api/devices/{deviceCode}/flows`
- 采购：`POST /api/purchase/apply|approve|receive`、`GET /api/purchase/list`
- 借用：`POST /api/borrow/apply|approve|lend|receive|return/apply|return/confirm`、`GET /api/borrow/list`
- 流转：`GET /api/flows`、`GET /api/flows/byTxHash/{txHash}`
- 仪表盘：`GET /api/dashboard/stats`

## 8. 演示流程
1) supplier 登记设备
2) hospital 发起采购 -> supplier 审批 -> hospital 收货
3) hospitalB 借用 -> hospitalA 审批 -> 借出 -> 收到 -> 归还申请 -> 归还确认
4) regulator 在流转页按设备与 txHash 查验
